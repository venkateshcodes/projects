# 📊 Sales Insights Dashboard  

🚀 A powerful **Excel-based dashboard** for analyzing and visualizing sales performance across quarters.  
This project is designed to provide **business insights** into revenue, customer acquisition, and performance against targets.  

---

## 📂 Project Structure  

- **Data Sheet (`Data`)**  
  Contains the raw and structured sales data including **quarterly sales (Q1–Q4 2023)**, KPIs, and active tables for analysis.  

- **Dashboard Sheet (`DASHBOARD`)**  
  - 🏆 **KPI Overview**  
  - 📈 **Revenue: Actual vs Target**  
  - 👥 **New Customers: Actual vs Target**  
  - 📊 Other visualization placeholders for sales insights.  

- **Copyright Sheet (`©`)**
